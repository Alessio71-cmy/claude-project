# Clash Display

I file `ClashDisplay-{400,500,600,700}.woff2` vengono scaricati automaticamente
da Fontshare alla prima `npm run build` / `npm run dev` (vedi `scripts/fetch-fonts.mjs`).

Per forzare il download: `npm run fonts`.
